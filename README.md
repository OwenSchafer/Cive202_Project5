# Cive202_Project5
Analysis of National Household Travel Survey data for a coalition of midwestern state Departments of Transportation. 
The following relationships were investigated:
- How many trips were made in each census region
- Average number of trips made by a given size of household
- Prevalence of given transportation types among different household income levels
